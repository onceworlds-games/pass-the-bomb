# Pass the Bomb

Someone is holding a lit bomb: tag another player to pass it before it goes off. Whoever holds it when it blows is out, and the last one left wins. Bots fill the empty seats, so you can play alone or with friends.

**How to play:** move with WASD or the arrow keys (or the thumbstick on a phone) and press Space (or Dash) to dash. Touch someone to give them the bomb.

Play it at https://onceworlds.com/play/pass-the-bomb
